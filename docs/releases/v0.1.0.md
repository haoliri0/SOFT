# SOFT v0.1.0 — SymFT 2026-10-08

This first GitHub Release packages the `symft_26_10_08` CPU/CUDA update and its
main-based integration from PR #19. The Python distribution is **`symft==2026.10.8`**.
GitHub `v0.1.0`, the SOFT v2 implementation generation, and Python `2026.10.8`
are intentionally different identifiers. Existing Python `0.1.0`/`0.1.1` packages
and historical SOFT v1 tags are unchanged.

## Highlights

- Exact noisy, adaptive Clifford-plus-Pauli-rotation simulation with measurement
  records, detectors, postselection, reference normalization and `EXP_VAL` probes.
- Opt-in compiled CPU counts sampling with earlier detector checks, real-gauge
  FP64 execution, SIMD kernels and a general-executor fallback.
- Opt-in CUDA NVRTC specialization, packed/sparse noise expressions, symbolic
  detector scheduling and device-side count reduction.
- The main-based integration retains expectation/reference APIs and fixes the
  CUDA scalar measurement-record copy path.

The October 9 benchmarks report 2.97x faster d=5 cultivation on one Xeon Gold
5218R core, 10.56x on an RTX 4090, and 3.30x faster single-core distillation.
These are workload-specific FP64 sampling measurements, excluding preparation
and JIT compilation. They are historical measurements, not new release-time
benchmarks. See the [benchmark scope and evidence](https://github.com/haoliri0/SOFT/blob/v0.1.0/README.md#performance).

## Install

```bash
python -m pip install symft==2026.10.8
```

Portable CPU wheels cover CPython 3.9–3.13 on Linux x86_64/aarch64, macOS arm64,
and Windows amd64. Other Python/platform combinations are outside this wheel
matrix. Wheels disable host-native optimization and retain available runtime
SIMD dispatch. They do not contain the CUDA backend.

For CUDA, install a C++20 compiler, a CUDA toolkit with NVRTC and a compatible
NVIDIA driver, then build the tagged source (POSIX shell):

```bash
git clone --branch v0.1.0 --depth 1 https://github.com/haoliri0/SOFT.git
cd SOFT
SYMFT_PY_NATIVE=0 SYMFT_PY_ENABLE_CUDA=1 SYMFT_PY_CUDA_REAL_DOUBLE=1 \
  python -m pip install ./python
```

This command selects FP64. CUDA source builds otherwise default to FP32.
See the [Python guide](https://github.com/haoliri0/SOFT/blob/v0.1.0/python/README.md)
for architecture selection and API examples.

## Compatibility and limits

The existing CPU executor remains the default. Compiled CPU counts require
explicit `cpu_backend="compiled"`, one worker, dense state, detector
postselection and `max_k <= 10`; incompatible cases use the documented fallback.
CUDA JIT is opt-in and applies to compatible GPU-presampled-expression counts
with `max_k <= 10`. Full records and expectation probes use the general CUDA
path. Matching seeds across backends do not imply identical sample streams.
The later `measurement_major` API is not part of this release.

## Validation and assets

Publication requires portable SIMD and scalar C++ suites, Python API tests,
worker/statistics checks, documentation validation, an isolated sdist install,
and API tests for every wheel in the platform/Python matrix. CUDA device checks
are performed separately on the release candidate; other GPU architectures
are not certified by an RTX 4090 run. Archived 50-billion-shot experiments have
not been rerun for this release.

The [local validation record](https://github.com/haoliri0/SOFT/releases/download/v0.1.0/local-validation.json)
records the release candidate's CPU/CUDA outcomes, environment and source hashes.

Assets include 20 CPU wheels, one Python source distribution,
`release-manifest.json` (source commit and distribution hashes), and
`SHA256SUMS` (also covering the manifest). Verify downloaded assets with
`sha256sum --check SHA256SUMS` on systems providing that command. GitHub's
additional automatic source archives contain the complete tagged repository;
the Python sdist contains the Python package and its required C++ sources.

SOFT/SymFT uses Apache-2.0. Benchmark inputs retain their separate attribution
and license in the repository. Report problems through
[GitHub Issues](https://github.com/haoliri0/SOFT/issues), including the package
version, platform, backend, precision and a small reproducing circuit.
