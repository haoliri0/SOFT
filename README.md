# SOFT
a high-performance parallel **S**imulat**O**r for universal **F**ault-**T**olerant quantum circuits

## Instructions

You can find instructions for building and running SOFT in [Instructions.md](Instructions.md).


## Paper

For the first version of SOFT paper, see:

    Li, Riling, et al. “SOFT: A High-Performance Simulator for Universal Fault-Tolerant Quantum Circuits.” *arXiv*, 2025, arXiv:2512.23037.


## One thing to note

We are developing *SOFT v2*, which is expected to deliver **at least** a $3\times$ speedup over the first version.

Feel free to ask us ANY questions on the issue tracker — we'd be happy to answer them.
